# 삼깡이 외형 가이드 v1

확정 기준일: 2026-11-03. 살깡말깡 사용자와 이 대화에서 정한 **외형 제작 기준**이다. 새 그림·감정·모션을 만들 때 이 문서를 먼저 따른다. 정면·측면·후면을 수치화한 완성 모델 시트는 아직 아니다.

## 1. 최종 조합

| 캐릭터 | 채택한 외형 | 유지할 특징 | 채택하지 않은 변경 |
|---|---|---|---|
| 살깡이 · 찬성 | 기존 몸과 머리 + 부드럽고 당찬 눈썹 | 민트색, 복슬한 둥근 몸, 기존의 짧고 불규칙한 머리 돌기, 크림색 얼굴, 작은 검은 타원 눈, 볼터치, 짧은 손발 | 길고 매끈한 두 갈래 머리, 커진 반짝 눈, 흰 눈동자 하이라이트 |
| 말깡이 · 반대 | **기존 버전** | 피치색, 통통하고 둥근 몸, 기존 작은 둥근 머리 돌기, 크림색 얼굴, 검은 타원 눈, 궁금해하는 비대칭 눈썹, 짧은 손발 | 길쭉한 콩 모양 몸, 안으로 말린 머리, 중간안의 말린 머리 |
| 판깡이 · 진행 | **뉴 버전** | 라벤더색, 말풍선 꼬리처럼 짧게 안으로 말린 머리, 둥근 안경, 부드러운 종 모양 몸, 크림색 얼굴, 볼터치, 짧은 손발 | 기존의 단순한 둥근 머리 돌기로 되돌리기 |

선정 순서: 말깡이 중간안을 검토했지만, 이후 사용자가 “판깡이만 뉴 버전”으로 선택했다. 살깡이의 반짝 눈도 검토했지만 마지막에 “눈동자는 기존”으로 확정했다. 앞선 비교 이미지의 미채택 요소를 다시 섞지 않는다.

**외형 기준은 아래 비교 이미지의 B안이다. A안은 변경 전 참고용이다.**

## 2. 공통 화풍과 비율

- 도트가 드러나는 두꺼운 짙은 윤곽과 작은 픽셀 덩어리의 음영을 쓴다. 뉴 판깡이도 기존 둘과 **같은 정도의 도트감**으로 맞춘다.
- 복슬하고 말랑한 느낌을 유지한다. 매끈한 벡터 윤곽·넓은 유광 하이라이트·입체 플라스틱 질감으로 바꾸지 않는다. 화면 전체에 모자이크를 거는 방식도 쓰지 않는다.
- 머리와 몸이 이어지는 짧고 통통한 비율, 크림색 얼굴 영역, 볼터치, 작은 손과 보이는 짧은 발을 유지한다. 긴 다리·목·꼬리·새 귀·의상을 임의로 추가하지 않는다.
- 포즈가 달라져도 몸의 크기·얼굴 위치·머리 모양을 유지한다. 회전이나 눌림은 작은 감정 동작 범위에서만 허용한다.
- 살깡이·말깡이의 기본 눈은 단순한 검은 타원이다. 놀람·고민은 눈썹·입·기울임으로 표현하고, 반짝이는 눈동자로 교체하지 않는다. 판깡이는 승인 시안의 안경과 눈 표현을 유지한다.
- 실제 제작 시 같은 캔버스와 발 기준선을 맞춘다. 잘린 포즈마다 크기를 따로 키워서 캐릭터가 들쑥날쑥 움직이게 하지 않는다. 공통 캔버스 크기·도트 격자·수치 비율은 개별 자산 제작 때 확정한다.

### 색상 기준

이미지의 기본 색 관계는 승인 B안과 감정 보드를 따른다. 아래 값은 현재 `frontend/src/index.css`의 **UI 연결 색상**이며, 그림 전체를 단색으로 덮거나 원본 픽셀의 유일한 색이라고 취급하지 않는다.

| 용도 | 현재 UI 색상 |
|---|---|
| 살깡이 / 찬성 | `#9ee8c2` |
| 말깡이 / 반대 | `#f6b896` |
| 판깡이 / 서비스 강조 | `#c4b5fd` |
| 어두운 배경 | `#12122a` |

얼굴·볼터치·윤곽·음영의 정확한 팔레트와 색상별 픽셀 수는 아직 고정하지 않았다. 추가 제작 시 임의의 숫자를 확정 규격처럼 적지 않는다.

## 3. 감정과 작은 움직임의 기준

다음 3장은 위 외형 기준을 적용해 만든 **감정·모션 검토용 보드**다. 각각 6개 감정/자세와 한 동작의 3단계 키프레임이 있다. 개별 투명 자산이나 실제 움직이는 애니메이션 파일은 아니다.

| 캐릭터 | 감정·자세 | 모션 방향 | 이미지 |
|---|---|---|---|
| 살깡이 | 기본 / 발언 / 기대 / 고민 / 아하! / 수긍 | 준비 → 손을 펼치며 살짝 들썩 → 제자리 | [살깡이 보드](design/2026-11-03/character-guide/02-pro-emotion-motion.png) |
| 말깡이 | 기본 / 질문 / 살펴보기 / 걱정 / 아하! / 수긍 | 정면 → 살짝 갸웃 → 제자리 | [말깡이 보드](design/2026-11-03/character-guide/03-con-emotion-motion.png) |
| 판깡이 | 반가워 / 듣고 있어 / 잠깡! / 안내 / 생각 정리 / 네 선택이야 | 듣기 → 손 펼치기 → 쉬기 | [판깡이 보드](design/2026-11-03/character-guide/04-guide-emotion-motion.png) |

- 살깡이는 귀엽고 당찬 기대를 전한다. 날카로운 분노·공격적인 눈썹이나 구매를 강요하는 표현을 쓰지 않는다.
- 말깡이는 궁금한 점과 부담을 꼼꼼하게 짚는다. 악역·방해꾼처럼 표현하지 않는다. 돋보기는 살펴보는 상황에 맞게 사용하며 모든 포즈에 필수는 아니다.
- 판깡이는 듣고 안내하고 정리한다. 판사 소품·망치·저울·판결·점수·승패 표현을 붙이지 않는다. 안내의 짧은 말은 **“잠깡!”**이며 어미마다 무작정 “깡”을 붙이지 않는다.
- 작은 들썩임·갸웃·끄덕임·손 펼치기를 필요한 순간에 사용한다. 물건을 집어 옮기거나 큰 이동을 하는 새 동작은 이번 방향에서 보류했다.
- 캐릭터는 감초로 필요한 시점에만 등장한다. 모든 버튼·문장·카드에 반복해서 붙이지 않는다.
- 결과는 이득·불편·확인 필요를 전하고 사용자의 선택을 기다린다. 살래요 / 보류 / 안 살래요 중 무엇을 골라도 캐릭터가 승리·패배·보상·실망으로 유도하지 않는다.

## 4. 제작·구현 상태

- 이 문서의 우선순위: **최신 명시적 사용자 결정 → 이 가이드의 외형 규칙 → 승인 B안 → 감정 보드 → 과거 탐색 시안**. 생성 이미지의 작은 불일치는 새 규칙으로 채택하지 않는다.
- 기준 브랜치 `develop`의 `e1f5bc3`에는 이미 PR #52의 감정 시안 자산 교체가 들어 있다. 사용 파일과 감정 매핑은 [ASSETS.md의 v05 기록](ASSETS.md#깡이-감정-시안-교체-v05-2026-11-03)을 따른다. 이번 커밋은 가이드와 참고 자료만 추가한다.
- 3단계 모션 키프레임의 실제 재생, 공통 캔버스 재정렬, 모바일 최종 크기 점검은 이 문서 작성으로 완료된 것이 아니다. 기존 구현의 확인 범위는 [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)를 본다.
- **글자와 로고는 현행 디자인 유지**. 비교 이미지의 글자를 새 글꼴 파일이나 교체 요청으로 해석하지 않는다. 이번 작업에서 폰트·히어로·서비스 코드는 변경하지 않는다.
- 모든 새 포즈는 위 동일성·도트감·발 기준선·정지 상태 가독성을 확인한다. 모션 구현 시 움직임 멈추기와 시스템의 동작 줄이기 설정도 존중한다.
