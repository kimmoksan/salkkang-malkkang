# 사용자 테스트 진행안

상태: 진행안만 준비. 실제 참여자·관찰 결과는 아직 없다. AI 키 없이 예시 모드로 진행한다.

## 준비

- 최근 지원 가전 4종 중 하나를 고민했거나 구입한 사람 3~5명, 1인 10~15분.
- 시작 전 “공방은 미리 만든 예시이며 제품에 맞춰 실제 AI가 답하는 테스트는 아니다”라고 설명한다.
- 개인정보·실제 집 사진은 받지 않는다. 기록은 참여자 번호로 남기고, 녹화가 필요하면 당사자에게 먼저 동의를 받는다.

## 과제

1. 고민 중인 제품군에서 모델 하나를 찾고 구매 이유를 입력한다. 찾지 못하면 직접 입력한다.
2. 제품 확인 화면에서 확정된 사양과 미확인 정보를 각각 하나 설명한다.
3. 상황을 보고 찬반 근거를 펼친다. 질문에 답한 뒤 답을 바꾸고 어떤 주장이 달라졌는지 말한다.
4. 질문을 건너뛰고 결과로 이동한다. 확인하지 않은 사항을 하나 찾는다.
5. 살래요·보류·안 살래요 중 하나를 고르고 이유를 적어 요약을 복사한다.

진행자는 먼저 사용법을 알려주지 않는다. 막히면 위치·시간·기대했던 동작을 기록한 뒤 최소한으로 돕는다.

## 마지막 질문

- 이 서비스가 구매 결론을 내렸다고 느꼈나, 스스로 결정했다고 느꼈나?
- 제품 사실과 가정·미확인의 차이가 보였나?
- 실제 구매 고민에 무엇이 도움이 됐고 무엇이 빠졌나?
- 가장 헷갈린 화면이나 문구는 무엇이었나?

테스트 뒤 실제 관찰만 채운다. 구매 판단을 AI의 판결로 오해하거나 미확인 사양을 사실로 읽으면 우선 수정한다. 예시 공방의 품질을 실제 AI 응답성 검증 결과로 기록하지 않는다.
