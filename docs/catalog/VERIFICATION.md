# 제품 카탈로그 검증 근거

확인일: **2026-10-30 (한국 시간)**. 대상: 삼성·LG × 4개 제품군 × 3개 = **24개 판매 모델/구성**. 24개 제품군을 새로 만든 것이 아니다.

## 선정·확인 기준

- 제조사 공식 상세 스펙 표로 사양을 확인하고, 별도로 실제 판매 페이지에서 정확한 모델명·가격·구매하기 표시를 확인했다. 단순 HTTP 200, 검색 노출, 공식 소개 페이지 존재만으로 판매 중이라고 판정하지 않았다.
- 기존 22개 후보가 실제 판매 중임을 재확인하고 LG 공기청정기 2개를 보완했다. 각 브랜드·제품군의 용량, 설치 방식, 주요 라인을 대표하도록 골랐다. 객관적인 시장점유율·판매량 1~3위라는 뜻은 아니며, 전 시장의 최다 판매 순위는 미확인이다.
- 판매 확인은 페이지의 주문 가능 표시를 확인한 범위다. 결제·배송지별 설치 가능 여부·판매자 실재고·최종 주문 성립은 검증하지 않았다. 판매 상태는 이후 변동될 수 있다.
- 24개 공식 페이지와 24개 판매 근거는 직접 HTTP 200 응답을 읽었다. 21개는 11번가 판매 페이지, B72WW·AS356NSMA·HY856RSAAP는 LG 공식몰의 실제 구매 페이지다. 후자의 사양·판매 출처 URL은 같지만 확인 항목은 각각 분리했다.
- 판매처의 사양이나 검색 요약은 JSON 사양의 근거로 사용하지 않았다. 삼성 스펙은 공식 페이지의 스펙 탭이 불러오는 공식 응답까지 확인했다.

## JSON 유지·미확인 처리

- 최상위 배열 및 model, brand, category, name, url, status, p, checked_at 유지. 기존 22개 항목의 p 필드명을 모두 보존했다. 출처 확장 필드는 JSON에 추가하지 않았다.
- 총 273개 사양 필드 중 271개를 공식 표와 대응시켰고, 의미가 모호한 2개는 문자열 `미확인`으로 보류했다. O/X, 있음/없음, 숫자 문자열 등 제조사별 기존 문자열 형식은 유지했다.
- RG20WN·RG18WNST의 기존 `듀얼 인버터 히트펌프` 키에는 부품명 `듀얼 인버터 컴프레서+`가 값으로 들어 있었다. 키 의미를 임의로 고치지 않고 해당 값은 `미확인`. 공식 표에는 각각 `건조방식: 듀얼 인버터 히트펌프`, `듀얼 인버터 컴프레서+: O`라고 되어 있다. 추후 필드 의미를 확정할 때 이 두 사실을 구분해야 한다.
- HY856RSAA 기존 후보 주소는 404였다. 현재 실제 구매 가능한 공식 판매 코드는 **HY856RSAAP**(본체 HY856RSAA + 급수비커 + 알레르겐 특화필터)다. JSON model/name/url은 이 판매 구성을 정확히 표시하고 p에는 해당 페이지의 본체 스펙을 기록했다. 본체 단품과 패키지를 두 제품으로 중복 집계하지 않았다.
- 하이드로타워 면적은 공식 상품 스펙 표의 66.0㎡를 채택했다. 별도 효율 인증 검색에는 77.4㎡가 나타나므로 조건·필터 구성에 따라 다를 수 있으며 이를 합치거나 성능을 추정하지 않았다. 소비전력 660W도 공식 표 값이며 항상 그 전력을 사용한다는 뜻으로 해석하지 않는다.
- 삼성 공기청정기 사용 면적은 공식 스펙의 `사용 면적(청정)`에서 확인해 기존 `(제품명 기준)` 설명을 제거했다.
- LG 로봇청소기 크기·무게는 본체 구역 값을 유지했다. 같은 이름의 스테이션 필드를 덮어씌우지 않았다. `출시년월`은 공식 `동일모델의 출시년월`에 대응한다.
- 에너지 등급은 확인일의 공식 상세 표 값을 그대로 채택했다. 판매처 제목의 과거 1등급 표기와 혼합하지 않는다. 등급 제도 변경 원인·시행일은 이번 조사에서 별도 검증하지 않았다.
- 구매 페이지가 있어도 주문 버튼이 없거나 일시품절인 링크는 제외했다. 예: VR90F01AAG의 11번가 상품 9528628102는 일시품절 표시가 있어 미채택했다.
