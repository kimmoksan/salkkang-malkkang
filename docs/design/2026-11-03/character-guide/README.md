## 최종 제작 지시 요약

다음은 생성 시 사용한 제작 지시의 한국어 요약이며 원문 프롬프트의 전문은 아니다. 기준 이미지가 포함된 반복 편집으로 제작했다.

1. **최종 비교안**: 기존/수정 메인 A/B 구도를 유지하고 아래 살깡이의 눈만 위 기존안과 같은 작은 검은 타원으로 되돌린다. 흰 하이라이트·커진 애니메이션 눈을 금지한다. 부드러운 눈썹, 새 판깡이, 기존 말깡이, 나머지 화면은 유지한다.
2. **살깡이**: 승인 B와 기존 전신 그림을 참조한다. 기존 복슬한 몸·짧은 머리 돌기·검은 눈을 유지하고 둥글고 당찬 눈썹을 사용한다. 기본/발언/기대/고민/아하!/수긍을 3열 2행으로 그린다. 하단에는 준비 → 손 펼치며 살짝 들썩 → 제자리의 세 프레임을 둔다.
3. **말깡이**: 승인 B의 기존 피치 캐릭터와 기존 전신 그림을 참조한다. 작은 둥근 머리 돌기와 통통한 몸을 유지하고 말린 머리·길쭉한 새 몸은 쓰지 않는다. 기본/질문/살펴보기/걱정/아하!/수긍과 정면 → 갸웃 → 제자리의 세 프레임을 그린다.
4. **판깡이**: 승인 B의 뉴 판깡이를 참조한다. 말풍선 꼬리 같은 짧은 머리 말림·안경·부드러운 종 모양 몸을 유지한다. 반가워/듣고 있어/잠깡!/안내/생각 정리/네 선택이야와 듣기 → 손 펼치기 → 쉬기의 세 프레임을 그린다. 판결·승패·구매 선택에 대한 보상 표현은 금지한다.

공통: 기존 수준의 도트 윤곽과 디더 음영, 크림색 얼굴·볼터치·작은 손발을 유지한다. 감정 보드는 아이보리/라벤더 배경의 검토 시트로 만들고 큰 이동·물건 운반은 넣지 않는다. 원본 식별자와 실제 크기·해시는 manifest.json에 기록했다.
